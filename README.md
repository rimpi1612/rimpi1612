## What I work on

- **Limits for coding agents with real access.** Controls enforced by the harness instead of the prompt, so an agent cannot push, deploy or commit credentials on a plausible but wrong instruction.
- **Checking model output before it can cause harm.** Verification layers over AI reviewers, and deterministic checks on an LLM whose output becomes accounting records.
- **Safety limits for a customer-facing AI assistant.** Input screening, output filtering, rate limits and pause-and-alert, with a clear decision on how each control fails.
- **Access control and audit.** One enforced authorization path, tenant isolation in the database, and audit trails that can answer who did what and when.

Most of this work is in private repositories. The portfolio describes it in general terms, including what each piece does not yet show.
